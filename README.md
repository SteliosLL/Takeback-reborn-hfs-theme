# Takeback-reborn-hfs-theme
A port of the classic takeback HFS2 theme to HFS3 with a lot of imporvements and extra functionality

## New features (compared to the HFS2 theme version):
-Modern media player integration which can play all sorts of video and audio formats. You can load a subtitle by opening the file menu on a .srt or .vtt file. Subtitle offsetting option available.

-The Mini media player has been improved to support more audio file formats. Also added more playback options (e.g. include subfolders in the playlist). And other smaller improvements...

-Upgraded the Text viewer to support syntax highlighting for many of the popular programming languages.

-Nav bar has been replaced with the one from HFS3 but has been styled to fit the takeback theme.

-Of course all the default HFS3 features are all available.
